# 앱 라우팅 기술 시험용 fixture

이 폴더는 P0~P2의 격리된 자동 검사와 사용자가 수행하는 서명 Mac 시험에 필요한 비밀 없는 입력만 둡니다.

## 허용되는 입력

- 연결할 수 없는 가짜 키와 예약 문서 주소만 사용합니다.
- 시험 앱의 서명 식별자와 팀 식별자는 Host Harness가 선택한 서명 앱에서 읽고, 실행 요청을 만든 뒤 즉시 지웁니다.
- fixture 준비 여부는 파일 내용을 읽어 추론하지 않고, 서명 Mac 체크리스트를 완료한 사용자가 Harness에서 명시적으로 선택합니다.

## 금지되는 입력

- 실제 WireGuard 설정 파일과 개인 키
- Team ID, 인증서 이름, 프로비저닝 UUID
- 실제 앱 이름·경로·번들 ID·서명 식별자
- 실제 팀 식별자
- 실제 목적지, 도메인, DNS 질의나 패킷 내용

P2는 흐름 수신과 앱 신원 판독까지만 확인합니다. WireGuard 전달이나 제품 통합을 시험하지 않습니다.
