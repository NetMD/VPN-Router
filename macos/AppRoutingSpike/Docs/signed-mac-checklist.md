# 서명 Mac 수동 시험 체크리스트

이 문서는 사용자가 직접 승인하고 수행하는 P0~P2 시험용입니다. 빌드 성공만으로 Network Extension 활성화, 라우팅, DNS 또는 복구 성공을 주장할 수 없습니다. P3 WireGuard 전달과 제품 통합은 범위 밖입니다.

## 1. 실행 전 게이트

- [ ] 실제 개발 팀에서 App Proxy 계열 시스템 확장 권한을 발급받을 수 있음을 확인했습니다.
- [ ] Host Harness와 Transparent Proxy 시스템 확장을 실제 값이 저장소에 남지 않는 별도 식별자로 서명했습니다.
- [ ] 다른 DNS·광고 차단·백신·보안·VPN 제품을 Host Harness가 중지하거나 바꾸지 않음을 확인했습니다.
- [ ] 사용자 WireGuard 설정이나 개인 키를 선택하지 않았습니다.
- [ ] 공개 시험용 서명 앱 본체 1개와 통제 앱 1개를 정했습니다. 앱 이름·서명 식별자·팀 식별자는 화면이나 결과에 표시하지 않습니다.
- [ ] 가려진 fixture만 준비했습니다.

하나라도 확인할 수 없으면 설치나 시작을 진행하지 않고 signedMac 결과를 `inconclusive`로 남깁니다.

## 2. 설치와 사용자 승인

- [ ] Host Harness에서 설치 요청을 직접 눌렀습니다.
- [ ] macOS 시스템 확장 승인 창을 사용자가 직접 확인하고 승인하거나 취소했습니다.
- [ ] 취소했다면 다른 설정을 바꾸지 않고 `stopped` 또는 `inconclusive`로 종료했습니다.
- [ ] 실제 권한 값은 존재 여부만 기록하고 Team ID·인증서·프로비저닝 전문은 내보내지 않았습니다.

## 3. P2 흐름과 앱 신원

정책 적용 뒤 만든 새 연결만 판정합니다. 이전 연결은 `preExistingFlow`로 분리합니다.

| 앱 역할 | TCP v4/v6 | UDP v4/v6 | QUIC | DNS A/AAAA | 기대 결과 |
|---|---|---|---|---|---|
| `selectedApp` | 필수 | 필수 | 필수 | 필수 | 신원 관찰 뒤 P2에서 흐름을 명시적으로 닫음 |
| `controlApp` | 필수 | 필수 | 표본 | 필수 | 일반 인터넷 직접 통과 |
| `helper` | v4 필수, v6 표본 | v4 필수, v6 표본 | 표본 | A 필수 | 자동 포함하지 않고 별도 관찰 |
| `controlPlane` | v4/v6 필수 | v4 필수 | 해당 없음 | 필수 | 재귀 없음 |

- [ ] 앱 본체의 TCP와 UDP에서 `sourceAppSigningIdentifier`와 audit token 확인 결과가 안정적으로 일치했습니다.
- [ ] 선택 앱 실패가 일반 인터넷 직접 통과로 바뀌지 않았습니다.
- [ ] 통제 앱은 사이트 규칙과 관계없이 일반 인터넷을 유지했습니다.
- [ ] DNS·QUIC·IPv6 미확인을 성공으로 기록하지 않았습니다.
- [ ] P2 결과를 WireGuard 라우팅 성공으로 표시하지 않았습니다.

## 4. 수명과 안전 중단

- [ ] 앱 재실행 뒤 새 흐름의 역할이 같습니다.
- [ ] Transparent Proxy 재연결 뒤 이전 스파이크 상태가 남지 않습니다.
- [ ] sleep/wake 뒤 같은 결과로 회복하거나 안전하게 중단합니다.
- [ ] 주 네트워크 변경 뒤 재귀·누수 없이 회복하거나 안전하게 중단합니다.
- [ ] 다른 VPN 연결·해제는 사용자가 직접 수행했으며 Harness는 다른 제품을 조작하지 않았습니다.
- [ ] Host 또는 Provider 종료 뒤 스파이크 소유 상태가 남지 않습니다.

## 5. 정리 확인

다음 순서를 지켰는지 확인합니다.

1. 새 흐름 거부
2. Transparent Proxy 중단
3. 스파이크 설정 제거
4. 통제 앱의 DNS·IPv4·IPv6 일반 인터넷 확인

- [ ] 수동 `route`, `networksetup`, 시스템 DNS 변경을 사용하지 않았습니다.
- [ ] 정리 실패 시 추가 시험을 중단하고 결과를 `fail`로 기록했습니다.

## 6. 결과 판정

- `pass`: 해당 signedMac 검사 항목을 실제로 관찰했습니다.
- `fail`: 필수 흐름 누수, 통제 인터넷 손상, 재귀 또는 정리 실패를 관찰했습니다.
- `inconclusive`: 승인·권한·흐름 종류를 확인하지 못했습니다.
- `stopped`: 사용자가 중단했거나 안전 조건 때문에 중단했습니다.

자동 검사 결과는 `EvidenceTier.automated`, 이 체크리스트로 관찰한 결과만 `EvidenceTier.signedMac`으로 기록합니다.
