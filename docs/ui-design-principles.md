# VPN Router 공통 UI/UX 원칙

Last updated: 2026-07-31 KST

## 목적

Windows와 macOS는 같은 제품처럼 느껴져야 하지만 같은 화면을 복사해서는
안 됩니다. 두 앱은 작업 순서, 이름, 상태 의미와 주요 동작을 공유하고,
표현은 각 운영체제의 기본 사용법을 따릅니다.

## 두 플랫폼이 공유할 것

- 홈, VPN 프로필, VPN 사이트, 문제 해결, 설정의 다섯 영역을 유지합니다.
- 홈에서 현재 연결 상태, 선택한 프로필, 선택 사이트 수와 하나의
  연결·연결 해제 동작을 먼저 보여줍니다.
- 사용자가 선택한 사이트만 VPN으로 보내는 흐름을 짧고 쉬운 말로
  설명합니다.
- 코랄 강조색은 주요 동작, 현재 선택과 중요한 상태에만 제한해 씁니다.
- 기술적인 경로·DNS·확장·복구 정보는 문제 해결 화면에 둡니다.
- 실패 상태는 무엇이 실패했는지와 다음에 할 일을 함께 알려줍니다.
- 색만으로 상태를 구분하지 않고 아이콘, 글자와 접근성 이름을 함께 씁니다.
- 연결, 프로필 선택, 사이트 추가처럼 같은 동작은 플랫폼이 달라도 같은
  이름을 씁니다.

## 복사처럼 보이지 않게 하는 기준

- 다른 VPN 제품의 로고, 그림, 큰 원형 연결 버튼, 카드 배치나 문구를
  그대로 따라 하지 않습니다.
- Windows와 macOS 사이에서도 픽셀 단위 크기, 모서리, 여백과 창 구조를
  복사하지 않습니다.
- 장식만을 위한 그라데이션, 빛나는 구체와 의미 없는 배경 무늬를
  반복하지 않습니다.
- 제품의 핵심인 `이 기기 → 선택 사이트 → VPN` 흐름을 VPN Router만의
  시각 요소로 사용합니다.
- 한 화면의 기억할 만한 요소는 하나로 제한하고 나머지는 차분하게
  정리합니다.

## macOS 표현

- SwiftUI의 사이드바, 시스템 글꼴, SF Symbols, 키보드 이동과 창 크기
  조절을 그대로 활용합니다.
- 연결 동작은 큰 원형 버튼 대신 글자와 아이콘이 함께 있는 넓은
  직사각형 버튼으로 표시합니다.
- 홈에는 `이 Mac → 선택 사이트 → VPN` 연결 경로 띠를 표시합니다.
- 자동·라이트·다크 화면과 대비 증가, 동작 줄이기, VoiceOver를
  지원합니다.
- 카드에는 얇은 코랄 표식과 넉넉한 내부 여백을 쓰되, 정보 구조를
  가리는 장식은 넣지 않습니다.

## Windows 적용 안내

Windows 구현은 별도 Windows 작업 환경에서 진행합니다. Windows는 WinUI
탐색·창·키보드 관례를 유지하면서 위의 공통 작업 순서와 단어, 코랄
강조색, 연결 경로 개념을 적용합니다. macOS SwiftUI 코드나 수치를 그대로
옮기지 않습니다. 현재 WinUI 화면의 구체적인 수정 범위, 반응형 카드 배치와
Windows 검증 항목은 `docs/windows-ui-ux-handoff.md`를 따릅니다.

## 확인 항목

- 작은 창과 넓은 창에서 내용이 잘리거나 겹치지 않습니다.
- 키보드만으로 다섯 영역과 주요 동작에 접근할 수 있습니다.
- VoiceOver가 화면, 상태, 선택 여부와 동작 결과를 이해할 수 있게
  읽습니다.
- 자동·라이트·다크와 대비 증가 상태에서 글자와 주요 동작이 선명합니다.
- 연결 중이거나 실패했을 때도 현재 상태와 다음 동작을 쉽게 찾을 수
  있습니다.
